## 受付ページについて

今年度の創作部門公演では、当選者の来場を、紙の名簿ではなく「受付ページ」で記録します。

受付でタップした記録はその場でサーバーに保存され、同じ公演の受付をしているほかの端末にも、10秒ほどで自動的に反映されます。1つの受付を複数のスマートフォンで担当しても大丈夫です。

受付ページを開けるのは、5・6年生（創作部門）のアカウントです。
【赤字】来場を記録できるのは、その公演を行うクラスの生徒だけです。ほかのクラスの公演は閲覧のみです。

また、当選者は公演開始10分後までに受付を済ませる必要があります。
【赤字】公演開始10分後の時点で来場していない当選は無効となり、空いた席はキャンセル待ちの列から補填します。

## 受付ページの開き方

以下のリンクにアクセスします。

https://sousakuten-top.2026.kss-it.com/lottery/reception

学校のアカウントでログインしていない場合は、画面右上からログインしてください。

【画像：01-page-top.png】

上の画面の3段のボタンで、「日にち」「公演」「クラス」を選びます。
ページを開いた時点で、受付中（またはこれから始まる）公演と、自分のクラスが選ばれています。

## 当選者の一覧

【画像：02-performance-list.png】

上の画面のように、選んだ公演の当選者が一覧で表示されます。1行が1つの観覧枠です。

- 校内の当選者は、アカウント名（例：3A34）、「本人」「保護者」の区分、人数が表示されます。保護者の枠は、お子様のアカウント名で表示されます。
- 「来場 11/59名（8/39組）」は、来場済みの人数と、この公演の当選者の合計です。
- 一覧は10秒ごとに自動で最新の状態になります。すぐに更新したいときは「最新にする」を押してください。

【画像：05b-row-external.png】

校外の方は、アカウント名の代わりに受付番号（例：AE00002795）と抽選番号で表示されます。

## 来場を記録する

当選者が受付に来たら、一覧からその人の行を探してタップします。

【画像：03-row-waiting.png】

タップすると、すぐに「✓ 来場」と時刻が表示されます。

【画像：04-row-saving.png】

「保存中…」と表示され枠線が点線の間は、記録をサーバーに保存しているところです。保存は裏で行われるので、保存を待たずに次の人の行をタップして構いません。

【画像：05-row-arrived.png】

保存が終わると枠線が実線になり、来場時刻が確定します。

- 保護者の枠など2名の枠も、1回のタップでまとめて記録されます。
- 間違えてタップした場合は、もう一度タップすると取り消せます。
  【赤字】記録と取り消しができるのは、受付締切（公演開始10分後）までです。

## 当選者を探す

【画像：07-search.png】

「アカウント・受付番号・抽選番号で探す」に入力すると、一致する当選者だけが表示されます。

- アカウント名（例：4B、4B23）
- 受付番号（例：AE00046805）
- 抽選番号（例：0468）

のどれでも探せます。全角で入力しても大丈夫です。

## 受付締切について

受付締切は、各公演の開始10分後です。

| 公演     | 公演時間     | 受付締切 |
| -------- | ------------ | -------- |
| 第一公演 | 8:45～10:00  | 8:55     |
| 第二公演 | 10:20～11:35 | 10:30    |
| 第三公演 | 12:30～13:45 | 12:40    |
| 第四公演 | 14:05～15:20 | 14:15    |

【画像：06-countdown.png】

受付締切の横に、締切までの時間が表示されます。

【画像：06b-countdown-red.png】

残り5分を切ると赤く表示され、秒単位で数えます。

【画像：11-closed.png】

受付締切を過ぎると、一覧は自動的に締め切られます。

- 来場していない当選は「無効」と表示されます。
- それ以降は、来場の記録も取り消しもできません。
  【赤字】「空席 ◯（キャンセル待ち）」の数だけ、キャンセル待ちの列の方を案内してください。

## ほかのクラスの公演

【画像：08-read-only.png】

自分のクラス以外の公演も一覧を見ることはできますが、上の画面のように「閲覧のみです」と表示され、記録はできません。

## 表示されるメッセージ

【画像：10-notice-already.png】

「この座席は◯◯:◯◯に来場済みとして記録されています。同じチケットで2回入場していないか確認してください。」
ほかの端末ですでに来場が記録されている枠です。
【赤字】同じチケットで2回入場しようとしていないか確認してください。

【画像：09-notice-offline.png】

「通信できませんでした。電波を確認して、もう一度タップしてください。」
電波が悪く、記録を保存できませんでした。表示は元に戻っているので、電波を確認してもう一度タップしてください。

そのほかに、次のメッセージが表示されることがあります。

- 「記録に失敗しました。もう一度タップしてください。」
  保存中に問題が起きました。もう一度タップしてください。
- 「この公演の来場を記録できるのは、◯年◯組の生徒だけです。」
  自分のクラス以外の公演です。
- 「受付締切（◯◯:◯◯）を過ぎたため、この公演の来場記録は変更できません。」
  受付締切の後は、記録も取り消しもできません。
- 「◯◯：この座席は見つかりませんでした。チケットが破棄された可能性があります。」
  当選者がチケットを破棄するなどして、その枠がなくなっています。一覧の上に表示され、「閉じる」で消せます。

表示がおかしいときは、ページを再読み込みしてください。それでも解決しない場合は、IT委員会までお知らせください。
